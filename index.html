Начинаем с HTML

HTML задаёт структуру страницы: заголовки, абзацы, изображения и кнопки.

💡 Подсказка: HTML — это скелет сайта. CSS отвечает за внешний вид, а JavaScript — за действия.

Что нужно знать

  • Теги описывают элементы страницы.
  • Большинство тегов имеют открывающую и закрывающую части.
  • Можно менять код и смотреть результат в редакторе ниже.
